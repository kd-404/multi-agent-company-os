Evaluation

Every Design agent run is scored, not just logged: per-stage success rate and latency, plus a relevance score checking whether the finished image's own Vision tags actually ground back in the trend brief that was supposed to produce it. This is the lean stand-in for a Foundry evaluator + Application Insights setup — same (stage, metric, value) shape, swappable later with no dashboard change.

Relevance score over iterations

How grounded each generated design's Vision tags are in its own trend-research brief (0–100), across the last 30 runs. A pipeline that's "succeeding" but drifting off-brief shows up here even when every call returns 200.

Marketing Agent

Trend radar checks live research against what's already in the catalog — when it finds a real gap, it commissions a new design from the Design agent itself, it doesn't just note it. Caption drafts are built from each design's own trend research and Vision tags, no extra AI call per design.

Checkout Funnel

No payment provider is connected, so the shop's full-page checkout is a demo — no money moves — but every step a shopper reaches (opened, address, payment, paid) is logged here with their email, so you can see where people drop off.

Warehouse Agent
